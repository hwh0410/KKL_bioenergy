# V0.9.6｜迎賓水池、曲水流觴與景觀主軸分離

## 本版成果
- 以 `C04.PDF` 第7頁「圖4.2.2-1」的訪客區水景為參考，將單一 F022 景觀範圍進一步拆分為 **15 條可編輯 SVG 路徑**，涉及北側半環廣場、水池內外緣、曲水流觴、下方水景、兩側步道、入口階梯及放射圖樣。
- 每條曲線具有獨立 ID、名稱、`type` 與 `status`，儲存於 `data/eia-p07-fountain-landscape-v0.9.6.json`。
- `plan/eia-fountain-landscape-v0.9.6.svg` 是獨立繪製的近似幾何圖，可分別隱藏水、路、廣場、階梯、路樹；GitHub Pages 新增 V0.9.6 顯示模式。

## 重要的精度說明
- 圖上可以看出上方大型半環幾何、中段的蛇形曲水、下方圓池及兩側階梯、路樹等構造。但本版主要是**目視判讀 + SVG 曲線重建**，**沒有完全逐段吸附原始 PDF 的每一個貝茲控制點**。
- 本版不是「CAD 自動識別成功」；不能稱為與原始 CAD 曲線完全重合。
- 圖面坐標對應 PDF 第7頁 `fitz.Rect(112,52,665,452)` 以 2px/pt 渲染得到的 1106×800 圖面空間，非真實 GIS／CAD 世界坐標；0.5172m/px 仍為暫定參考。
- 圖中路樹為重建示意，未逐株辨認或量測。外觀與高度資訊不在本版範圍內。
- 原始 PDF 有複製限制；Repository 只發布重新描繪的簡化圖元，不散布大範圍原始向量線條。
