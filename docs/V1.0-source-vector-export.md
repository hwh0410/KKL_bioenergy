# V1.0 private source-vector export workflow

This branch adds reproducible extraction and QA tools for the historical EIA plan on PDF pages 7 and 8. The tools accept a user-supplied PDF path and write all source-derived SVG, GeoJSON, DXF, source overlays, and detailed source-index reports to a separate private output directory.

`analysis/c04_reconstruct.py` preserves page rotation and source path indices, keeps cubic Bézier controls in SVG, exports editable local-coordinate GeoJSON, and writes DXF layers by source primitive type. It does not assign building, road, tank, water, or expansion semantics. The source-item tier remains `unknown` until reviewed. DXF is not georeferenced.

`analysis/compare_private.py` compares the generated SVG linework with private PDF page renders. `analysis/register_pages.py` estimates a provisional page-7 to page-8 image transform from four manually selected overlapping windows and reports residuals. The image controls are not survey points.

`analysis/classify_expansion_zones.py` maps the page-8 legend colors to separate A/B/C candidate layers and retains source drawing/item IDs. The gray B region remains split into source-colored pieces; invalid source polygons are flagged rather than repaired. All expansion geometry remains historical and candidate.

Run tests with:

```bash
python -m pip install -r analysis/requirements.txt
python -m unittest discover -s analysis/tests -v
```

Do not commit the PDF, extracted vectors, private QA JSON, source overlays, or map exports unless the source owner confirms publication rights. Current public deliverables are the tools and tests only. No engineering geometry is promoted to `verified_source` by this workflow.
