## Provenance / coordinate conventions
* Source: historic EIA C04.PDF PDF page 7 (Fig 4.2.2-1) and page 8 (Fig 4.2.2-2).
* Page indices in PyMuPDF are 6 and 7, respectively. Original MediaBox is portrait, rotated by 90 degrees for display. Use `page.rotation_matrix` on source path coordinates, never a handwritten rotation assuming 842.
* Path group indices are only meaningful with the recorded PDF hash and PyMuPDF version. Individual stable source references should use `page:drawing_index:item_index`.
* Explicit `closePath` flags may be absent even where a graphic appears visually closed. Do not infer topology, object identity or underlying CAD layers.
* Scale endpoints must be measured in **display-page points**. Supply `--scale-x0 ... --scale-y0 ... --scale-x1 ... --scale-y1 ... --scale-m 60` only after independent endpoint inspection. Scale values are *not* georeferencing.
* Historic total area 204,820 m² is context, not perimeter fitting control. Earlier 0.51724 m/pixel is **provisional**.
* Existing V0.9 manually traced SVG data remain `candidate`; verified footprint/road/tank/pool outlines still require provenance, semantic checks, non-self-intersection QA and page-to-page controls.

## Review gates
1. Page rotation/crop and source inventory reproducible.
2. Scale-bar endpoints plus uncertainty independently measured.
3. Semantic object list and source path indices recorded privately; promote only with human check.
4. Ring continuity, endpoint tolerance, intersections, winding and holes verified.
5. Page 8 A/B/C overlays registered to page 7 with residuals, no assumption of contemporaneous construction.
6. Draw independent vector SVG/GeoJSON with explicit `verified_source`, `candidate`, `unknown`; review publication rights before public deployment.

Status: **preflight only**. No new engineering-verified contour or corrected scale certified. Public V0.9 layers remain as-is pending review.
