## 方法與精度
- 根據使用者提供 C04.PDF 第7頁原有向量資料，對照 **PDF 圖面原尺寸 2倍渲染**，選取可辨識設施的轉角及主要道路軸線，建立獨立概念地物。
- 不是直接恢復原始 CAD Layer、Block 或拓樸關係；候選輪廓邊角是人工確認後選取，**尚未逐段 Snap 到 PDF 原始線條**，不可稱為原CAD精度建築輪廓。
- 座標基準是 `fitz.Rect(112,52,665,452)` 裁切區的 **1106×800 畫面像素**，不是公尺、TWD97 或 WGS84。
- 路網只有中心線候選，**非道路兩側的精確邊線**；先不以環評道路寬度機械套線。
- 三廠預定地、廠區東側小型設施等有語意與範圍不確定性。均設定 `review_required:true`，低信心候選不進入工程尺寸統計。
- 原始 PDF 複製權限受限。GitHub 僅上傳**簡化、重新描繪的分類輪廓**，不公開原 PDF 的完整向量擷取檔。

## 下一步：開始精準描線
1. 以 PDF 原向量路徑建立「snap-to-nearest segment」幾何網格，依本版候選物件選定實際建築邊界。
2. 對每個多邊形檢查是否閉合、自交、重疊，並標記是否與來源 PDF 建築外緣一致。
3. 依圖上 0–60m 刻度做比例校正（掃描縮放與橫直軸是否一致需確認），另保存誤差估計。
4. 保留歷史工程圖的時間標籤，和2026年衛星現況各自呈現。
