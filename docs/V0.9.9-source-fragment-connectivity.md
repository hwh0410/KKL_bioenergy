# V0.9.9｜水景原始 PDF 向量片段與端點連接分析

## 目標
接續 V0.9.8（15 條手繪景觀路徑均未通過 80% 的來源近線覆蓋門檻），改採 **直接擷取原始 PDF 繪圖線段、分析來源端點及連通圖**。本次不再嘗試移動舊版 SVG 曲線到最近的任意筆畫。

## 真正使用的來源
- 使用者提供 `C04.PDF`，PDF 第 **7** 頁，圖 4.2.2-1。
- `PyMuPDF.get_drawings()` 擷取 PDF 原有的線段與三次貝茲指令，保存來源 `drawing index:item index`。
- 統一圖面像素基準：`fitz.Rect(112,52,665,452)`，渲染密度 2 px/PDF point。此座標非 GIS、地籍或 CAD 原始世界座標。

## 本次方法
1. 在原圖水景區域收集相交的來源線段；原始筆畫仍包含裝飾、文字、排線，不直接等同水池邊界。
2. 以先前目視辨識的五個環形區域作**搜尋窗**，要求片段落在指定半徑的容差帶內，且走向與當地半徑近似垂直。
3. 只計入符合上述條件的 PDF 原始片段，建立來源索引。
4. 以 1.5 圖面像素的端點距離，將相接片段分組，檢查能否形成來源一致的連續輪廓。

## 下一階段：從片段到可信輪廓
1. 優先對南端圓池採用**由原始來源線條形狀出發**的幾何偵測，不再固定推定的圓心／半徑。
2. 按同一 `drawing/item` 的原始貝茲控制點或線段終點，進行自適應切分和拓樸串接；避免因 35 px 的線長限制漏掉完整弧線。
3. 以圖上可明確辨識的圓池最外緣和內緣做視覺核對，逐個環檢查閉合、缺口、交叉及不同 CAD 筆畫混用。
4. 只有建立完成且通過校核的來源環，才替換 V0.9.6 手描曲線，並保留來源索引與殘差。
