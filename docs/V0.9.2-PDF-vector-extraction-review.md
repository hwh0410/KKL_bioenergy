## 轉出格式

1. **SVG**：可保留 PDF 頁面中的向量路徑、原始幾何關係與大部分視覺樣式。已在模型工作容器內輸出並用另一 SVG renderer 與來源 PDF 重繪比對；輪廓大致對齊。
2. **DXF（試驗性）**：保留 40,804 條裁切區相交的直線、1,436 個以12段折線近似的曲線及 442 個四邊形／矩形。是 **PDF路徑轉換**，**不是原DWG復原**。
3. DXF 僅建立 `PDF_STRAIGHT_LINES`、`PDF_CURVE_APPROX`、`PDF_QUAD_EDGES`、`PDF_RECTANGLES` 等**幾何形式**圖層，**沒有**原CAD的建築、道路、槽體等語意圖層。
4. SVG 和 DXF 的座標仍為裁切後的 PDF 繪圖坐標，非 WGS84、TWD97 或工程公尺坐標；先不要使用其座標測量工程距離。

## 關鍵限制

- 各 PDF drawing 群組可能包含數百至數千段路徑，甚至跨越不同物件，不能直接把 drawing 轉成單一「建築」。
- 部分標籤為轉成輪廓的路徑字形，文字辨識不完整。
- 現在已具備不靠人工重畫的**幾何參考底圖**，但尚需按地物意義（建築、道路、儲槽、景觀）建立新的語意圖層並驗證。
- PDF 資訊顯示 `copy: no`。在確認相關圖資可公開再散布之前，**先不把從原PDF直接還原的整張SVG及DXF上傳公開GitHub Pages**。本頁只公布技術檢測與彙總統計。
