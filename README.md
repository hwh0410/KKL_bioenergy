# KKL Bioenergy｜金門酒廠金寧廠 3D 廠區平台

以 Three.js 與 GitHub Pages 製作的互動式廠區模型，先建立既有廠區量體，後續用於規劃厭氧沼氣設施（AD）配置、工程量體與概念方案比較。

## 網站
預期 Pages 網址（須在 Settings → Pages 啟用 GitHub Actions，且帳號方案支援）：https://hwh0410.github.io/KKL_bioenergy/

## V0.4 功能
- 廠區 3D 量體、代表性入口地標、道路與植栽
- 立體／俯視切換、拖曳旋轉、平移、縮放
- 點擊量體查看示意資訊
- 建築標籤、道路／植栽開關、PNG 截圖
- 自動部署 GitHub Pages workflow

## 資料精度
**V0.3 依使用者提供的官方示意圖與北向衛星截圖重建主要量體及周邊道路；不是實際測繪成果。** 建築尺寸、位置、用途標示及朝向都需要在取得正射影像、廠區配置圖與照片後校核；目前不能作為距離或工程決策的依據。

## 開發路線
1. **V0.2：概念量體套繪（已完成初版）** — 依北向衛星截圖重新配置兩個主要建築群及可見儲槽。仍需地理配準與實際尺度校正。
2. **V0.3：現況量體** — 建築高度、屋頂型式、道路與主要設施校正。
3. **V0.4：圖層管理** — 分離既有設施和規劃設施的資料與顯示。
4. **V1.0：厭氧沼氣規劃** — 新增反應槽、預處理、沼氣儲存、公用設施與動線的方案比較（需符合實際工程條件）。

## 技術
純靜態 HTML + Three.js（透過 jsDelivr 載入），不需伺服器或後端。部署採用 `.github/workflows/deploy-pages.yml`，Push 到 main 後執行。

## 開啟 GitHub Pages
在 GitHub Repository 的 **Settings → Pages → Build and deployment → Source** 選 **GitHub Actions**。請留意此 Repository 如為 private，GitHub Pages 是否可用與方案權限有關；不能使用時可調整可見性或方案，先確認沒有不適合公開的資料。

## V0.2 資料依據
- 使用者提供：金門酒廠官方平面示意圖、Google 地圖位置圖、北向衛星截圖。
- 模型以截圖中的像素相對位置人工描繪；沒有將 Google 衛星影像檔重新發布於網站。
- 所有建築高度、模型尺度與名稱皆為概念示意，尤其不得用於建廠位置、用地邊界與法定退縮距離之判定。
- 後續需以有授權的正射影像、建築尺寸、高程、用地資料及現場資料校準。

## V0.3 道路與量體檢查
- 將南側桃園路、東側聯外道路、道路延伸、出入口及主要內部通道加入場景。
- 模型建築物以旋轉矩形 footprint 進行 SAT 重疊檢查；儲槽加入占地避讓，內部道路以分段裁切避開建築物與儲槽。
- 植栽會避開建築與道路一定範圍。
- 目前道路線形、建築和設備高度皆由截圖示意判讀，不是測量基準；未來工程配置須用正式地形／地籍／竣工資料校正。

## V0.4 路線曲面與比例校正
- 參照使用者 2026-11-17 提供的兩張北向 Google 地圖截圖人工描繪桃園路、東側聯外道路、路口、廠內主要通道，共 18 條道路中心線。
- 改用 Catmull–Rom 曲線取樣，產生連續道路帶狀網格，不再以分段方塊顯示。
- 依使用者標記的面積 **282,716.95 平方公尺** 與周長 **約 2.41 公里**，估算每個參考影像像素約 **1.089 公尺**；這不是地理配準、正式測量或法定地籍界線。
- 維持建物旋轉矩形占地排除重疊、儲槽避讓、道路與建物避讓、植栽避讓。
- 注意：建物取自先前另一張衛星截圖的初步套繪，透過暫定影像轉換置入此次地圖座標；建築與道路的精確吻合仍待後續核對與修正。

## V0.5 — OSM 道路向量整合
- 道路來源：使用者於 Overpass Turbo 匯出的 `export.geojson`，保留金寧廠周邊 **67 條** OSM 道路線段，存於 `data/roads-osm.geojson`。
- 道路使用原始 WGS84 經緯度，載入時以當地近似公尺投影轉為 Three.js 場景座標；以已知路口進行**暫定視覺對位**，不是正式地理配準。
- 利用連續帶狀三角網格繪製道路，保留道路類別（secondary / tertiary / service / secondary_link / track）。
- 既有廠區建築仍為人工示意量體；如與 OSM 路線衝突，原型將避讓而非推定道路錯誤，未來需地理配準並重新套繪建築。
- **資料來源與授權：© OpenStreetMap contributors，Open Database License (ODbL) 1.0。** [OpenStreetMap copyright](https://www.openstreetmap.org/copyright)。
- 因為只查詢附近路段，未必包含所有廠內私人道路；不應將現有道路完整度用於正式工程設計。
