# 金門酒廠金寧廠｜2D 平面配置重建（V0.8-R）

此 Repository 目前以 **2D 平面配置圖** 為 GitHub Pages 首頁。依使用者提供的金寧廠官方示意圖手工數位化，不沿用舊 3D 模型的建物配置；後續確認平面圖後，再拉出建築及桶槽量體。

## 線上預覽
https://hwh0410.github.io/KKL_bioenergy/

## 資料檔
- `plan/kinmen-jinning-2d.svg`：分組向量配置底圖，可用 Illustrator、Inkscape 等編輯。
- `index.html`：2D 互動檢視器（平移、縮放、圖層開關、物件名稱、下載 SVG）。
- `data/`：前幾版 GIS 與 3D 原型資料，為避免誤用 **不參與本版的 2D 定位**。舊 3D 程式可由 Git 歷史版本回溯。

## 指定符號與配色
- 白色方形建築：`#FFFFFE`
- 棕色方形建築：`#BA908C`
- 白色圓形桶槽：`#FFFFFE`
- 綠色圓形路樹：`#9DBA8A`
- 道路：`#EDF2EE`

## 本版圖元數
建築 18、桶槽圓形 33、道路/步道 21、路樹約 479（均屬示意數位化數量）。所有圖元分層並具 `id` 便於後續編輯。`annotations` 景點標籤預設隱藏。

## 精度與用途
參考使用者先前提供的 Google Maps 量測 **282,716.95 平方公尺**、**周長約 2.41 公里**。這兩個數值僅用來掌握整體規模；這張 SVG 是相對位置描圖，**尚未地理配準、不具可直接量距的工程精度**，亦不等於法定地界／測量成果。

## 開發方向
1. 使用者核對 2D 各圖層位置、尺寸比例、建築／槽體數量。
2. 完成圖面校正後，建立尺寸／公尺座標控制點。
3. 在 2D 底圖上逐步拉出 3D 廠房及桶槽量體。
4. 最後才加入行政大樓、迎賓水池、酒瓶地標等代表性實景造型，並規劃未來厭氧沼氣場。

道路和位置資料參考使用者提供的示意圖；網站不重發 Google 地圖影像。
