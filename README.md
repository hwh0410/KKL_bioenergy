# 金門酒廠金寧廠｜高精度 2D 平面配置（V0.8-R2）
以使用者提供的 **887 × 475 px 示意圖** 為唯一配置參考，採用圖像顏色分割、連通元件與邊界追蹤重新數位化。新版不使用之前 V0.8-R 人工估算的道路中心線、建物座標和樹列。

## 網址與檔案
- [線上互動版](https://hwh0410.github.io/KKL_bioenergy/)
- [SVG 向量原稿](plan/kinmen-jinning-2d.svg)
- `index.html`：平移／縮放／圖層切換與 SVG 下載。

## 圖層與顏色
- `land`：原圖草地與淺綠色區域（#E1F0C7）
- `roads`：道路（#EDF2EE），依來源道路像素區域追蹤邊界。
- `buildings-white`：白色建築（#FFFFFE），約 19 個連通圖塊。
- `buildings-brown`：棕色建築（#BA908C），3 個主要方形圖塊。
- `tanks`：白色圓形槽體／設施，辨識 9 個圖塊（部分可能被圖例遮住）。
- `circular-facilities-unconfirmed`：原圖棕色圓形符號，辨識 12 個，**用途尚待確認**，不逕自歸類為桶槽。
- `trees`：#9DBA8A 圓點圖塊，約 996 個候選區域；屬像素元件數，不能當成經查證的實際樹木株數。
- `annotations`：7 組已知景點標籤，依原圖標籤位置標記。

## 與前版的差異
1. 前版採人工路徑，路口與彎道易偏移；新版採原圖顏色區域向量化，將道路與建築的形狀鎖定在相同影像坐標系。
2. 路樹不再人工等距分布，而是自原圖綠色圓點的連通元件追蹤位置。
3. 不對標籤遮蔽的構造任意補線；原始圖面未顯示的資料一律保留未知。
4. 以 SVG 向量圖層管理；後續完成圖面確認後，才開始 3D 拉量體。

## 精度限制
- 這是**來源圖片像素座標對齊**，不是正式地理配準，不代表廠房長寬、高度、公尺座標、法定地界、地形高程。
- 282,716.95 m² 面積與周長約 2.41 km 是使用者於 Google Maps 的參考量測，不能直接套用到 SVG 每個圖元的工程尺寸。
- 色塊與向量轉換可能造成少量邊緣平滑差異；路樹數量以可辨識色塊為準。
- 原始照片上的黃色標籤會遮住其下結構；在缺乏原始無標籤圖前不虛構遮擋部分。

後續只在確認平面外框、道路與樹列之後，校正實際尺度，再建立廠房、儲槽與代表性建築的 3D 模型。
