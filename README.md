以上是按掃描圖人工描繪的**初步向量輪廓**，未經完整地理配準或工程測量；不應將第8頁規劃的建築逕行視為現今已竣工設施。

## 基準與索引

- `docs/V0.9-EIA-modeling-baseline.md`：原始環評的 21 項土地使用面積、道路寬度、出入口與建模清單。
- `data/eia-v0.9-baseline.json`：同一批建模基準的結構化資料（總面積 **204,820 m²**）。
- `data/eia-v0.9-feature-index.json`：各 SVG 圖元編號／名稱／來源頁碼，方便後續逐步修正。
- `data/roads-osm.geojson` 等早期試驗資料仍保留，但**不參與目前環評配置圖的尺度／幾何基準**。

## 後續校正順序

1. 以原始 PDF 第7頁擴大比對建築外框、出入口與道路曲線；對照圖上 0–60m 刻度校核掃描影像比例。
2. 以第8頁校正 A/B/C 地塊外框、規劃設施的位置，核對第7頁共有的既有控制物件。
3. 在同一組經校正的控制點上完成兩張歷史圖的地理座標統一；之後再以最新可用資料建立「現況」圖層。
4. 複核每一棟的名稱、用途、用地範圍與實際建築 footprint（環評用地面積不等於建築物占地）。
5. 完成 2D 圖審後再逐棟拉 3D 量體，並另設規劃中的厭氧沼氣廠圖層。
