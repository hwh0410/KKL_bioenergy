# 金門酒廠金寧廠 C04 第 7 頁 3D 概念量體 V1.0

本模型依 C04 歷史配置圖重建主要廠房、道路、迎賓圓池與步道的相對位置，用於場區配置檢視。網站不包含原始 PDF、頁面影像或完整 PDF 向量資料。

- `KKL_Jinning_C04_p07_massing_v1.0.glb.gz`：gzip 壓縮的 GLB；檢視平台載入時會解壓縮，下載按鈕會提供可直接使用的 `.glb`。
- `preview.jpg`：3D 未能載入時顯示的預覽。
- `metadata.json`：比例換算、幾何狀態與限制。

**精度界線：** C04 是歷史規劃圖；足跡是依圖面人工簡化數位化，並非逐段通過 PDF 原始向量端點閉合驗證；高度是示意估值。模型用於配置討論，不可作施工或竣工判定。
