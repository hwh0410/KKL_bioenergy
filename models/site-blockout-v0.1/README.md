# Kinmen Kaoliang Jinning Plant — 3D Blockout v0.1

This GLB is a conceptual site-visualization blockout generated from the repository's indicative GeoJSON layers. It includes approximate factory building masses, visitor facilities, OSM roads, simple water basins, a curved pedestrian path, a landscape mound, and bottle landmarks.

- [Download the GLB](./KKL_Jinning_site_blockout_v0.1.glb)
- [Preview image](./preview.jpg)
- [Coordinate and precision metadata](./metadata.json)
- [Generator script](../../analysis/build_site_blockout.py)

The model uses a local tangent-plane coordinate frame in metres. Building footprints and heights are approximate; the ground is flat; visitor features are simplified. This is for visualization and facility-placement review, not an as-built survey or engineering model. It does not include the C04.PDF or any PDF-page reproduction overlay.
