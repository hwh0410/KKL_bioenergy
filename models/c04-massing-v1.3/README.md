# KKL Jinning C04 page 7 massing V1.3

Editable GLB massing based on the historical C04 page 7 plan. V1.3 corrects four building/road proximity issues found when the footprint overlay was checked against the plan coordinate grid. The S-shaped watercourse remains the user-confirmed connection between 迎賓水池 and 寶月新泉.

## Files
- `KKL_Jinning_C04_p07_massing_v1.3.glb.gz`: downloadable gzip-compressed GLB.
- `preview-top.jpg`: top-down view for footprint/road review.
- `render-context-isometric.jpg`: full site context render.
- `render-visitor-landscape.jpg`: visitor area render.
- `metadata.json`: coordinate scale, model inventory, QA summary, and limits.
- `road-clearance-QA.md`: simplified overlap and clearance report.

## Limits
Historical plan reconstruction for visualization; not an as-built survey, construction drawing, or verified georeferenced dataset. Heights, exterior treatment, equipment details, and surrounding context are illustrative. The PDF, extracted source vectors, and source-image overlay are not included.
